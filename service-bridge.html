BRiDGE est une plateforme de structuration de la donnée survey/projet.

Core · Data Lake · Data Management

Core : l'activation du Data Lake, pas un simple abonnement.

Le Core BRiDGE ouvre l'environnement projet. Il configure le Data Lake selon le CRS, les seuils QC et la taxonomie BRiDGE v2. Il active aussi le Data Management : nommage, intégrité des fichiers, structure documentaire et cohérence des répertoires selon les exigences client.

Core module 1

Survey Modules

Les modules Survey capturent la donnée là où elle naît : positionnement, LBL, USBL, calibrations, QC, SIMOPS et monitoring. Chaque opération terrain devient une donnée structurée, horodatée et qualifiée dès l'ingestion.

Core module 2

Data Lake

Le Data Lake BRiDGE n'est pas un répertoire partagé. C'est la mémoire opérationnelle du projet : chaque donnée est classifiée, versionnée, historisée et interrogeable en temps réel.

Core module 3

Data Management

Le Data Management garantit que les données restent propres, cohérentes et défendables : nommage, intégrité, structure, maturité, audit trail, cohérence documentaire et conformité projet.

Moteur opérationnel

Les modules Survey alimentent le Data Lake.

Chaque module n'est pas seulement une fonction de contrôle : c'est une source de données qualifiées pour le Data Lake projet.

QC Positionnement

Cross-check indépendant des outputs de positionnement

Validation des crosslines, répétabilité, deltas USBL/GNSS et critères d'acceptance. Alertes GREEN/AMBER/RED configurées sur vos specs. Chaque alerte et chaque validation entrent dans le Data Lake avec horodatage et traçabilité complète.

3 000 €HT / mois
Mob & Calibration

Vérification des offsets capteurs, analyse des résidus USBL, comparaison des mesures redondantes et revue experte systématique avant le premier cast opérationnel. Les certificats validés deviennent la référence Data Lake du projet.

3 500 €HT / mois
LBL Acoustique

Deuxième œil sur le positionnement acoustique

Relecture indépendante des outputs LBL, cross-checks baseline, détection de transponders suspects et validation des profils SVP. Chaque décision de validation est capitalisée dans le Data Lake projet.

3 000 €HT / mois
SIMOPS / COMOPS

Contexte multi-navires structuré

Suivi des opérations simultanées et des contextes de proximité. Les événements, décisions et fenêtres opérationnelles sont historisés pour analyse, défense documentaire et retour d'expérience.

5 000 €HT / mois
MRU Monitoring

Ingestion des données MRU via Edge Device, transmission temps réel vers dashboard shore, alertes automatiques sur critères d'installation et audit trail HSE complet dans le Data Lake. Module en cours de développement.
